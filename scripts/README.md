# Scripts

- `export-abi.ts`: xuất ABI đã compile sang frontend; chạy `npm run export:abi`.
- `demo-local.ts`: demo thắng/hòa/không phiếu trên mạng mô phỏng, đo gas; `npm run demo:local`.
- `seed-election.ts`: thêm dữ liệu thử vào deployment local; `npm run seed:local`.
- `export-deployment.ts`: ghi metadata deployment local/Sepolia và `frontend/.env.local`.
- `smoke-sepolia.ts`: kiểm tra chỉ đọc deployment Sepolia; `npm run smoke:sepolia`.
- `local-contract.ts`: helper dùng chung, chỉ chạy trên chain 31337.

Không tạo script giả báo thành công cho nghiệp vụ chưa triển khai.
