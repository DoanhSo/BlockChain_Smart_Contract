# Scripts

- `export-abi.ts`: xuất ABI đã compile sang frontend; chạy `npm run export:abi`.
- Tiếp theo: thêm `seed-election.ts` khi có hàm quản lý ứng viên/cử tri.
- Tiếp theo: thêm `smoke-sepolia.ts` khi hoàn thiện contract và có deployment thật.

Không tạo script giả báo thành công cho nghiệp vụ chưa triển khai.
