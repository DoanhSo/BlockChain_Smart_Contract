# Báo cáo học phần

1. Đặt vấn đề: bối cảnh, mục tiêu, phạm vi.
2. Cơ sở lý thuyết: Ethereum, EVM, ví, giao dịch, gas, Solidity và công cụ.
3. Triển khai: thiết kế, mã chính, kiểm thử, triển khai và kết quả thực tế.
4. Kết luận: giá trị, hạn chế, khả năng mở rộng.

Tối đa 40 trang, nộp bản cứng theo đề. Phân bổ chi tiết trong tài liệu kế hoạch.
